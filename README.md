# Claude & Codex Status for Stream Deck Neo

Claude CodeとCodexのタスクセッションを、Stream DeckのLCDキーでリアルタイム表示するmacOS向けプラグインです。画面を切り替えている間にエージェントの返信が完了したら、「確認待ち」と実際のタスク名で知らせます。

## Neoでのおすすめ配置

1ページ目の8キーを次のように配置します。

| 位置 | アクション |
| --- | --- |
| 上段1 | `Claude Code 概要` |
| 上段2 | `Codex 概要` |
| 上段3 | `最新更新タスク` |
| 上段4 | `1つ前の更新タスク` |
| 下段1 | `2つ前の更新タスク` |
| 下段2 | `3つ前の更新タスク` |
| 下段3 | `4つ前の更新タスク` |
| 下段4 | `Claude 5時間 + Codex 週間使用率` |

Claude CodeとCodexを合わせ、作業中・確認待ち・エラーのタスクをエージェント側の最終更新日時が新しい順に最大5件表示します。状態による優先順位付けはしません。Claude/Codexのメインタスクが終了したとき、Codexのタスクをアーカイブしたとき、またはタスクキーを押して確認済みにしたとき、そのタスクは一覧から外れます。返信の完了だけでは確認待ちを維持し、エージェント側の最終更新日時も変更しません。

概要キーは中央に `CLAUDE` または `CODEX`、その下に `確認待ち` と `作業中` の件数を大きく表示します。エラー件数は概要に表示せず、該当する実タスクキーにだけ表示します。構成は1ページのみです。

旧 `AI Agent Status` は新規追加一覧から非表示になりました。すでに配置済みの場合は、そのキーを削除できます。

各タスクキーにはエージェントのロゴと名前、状態、実際のセッション名、最終更新からの時間が表示されます。背景はすべて黒で、右下にはエージェントの約76pxのロゴを透かしとして表示します。Claude Codeはオレンジ枠と透明度70%のオレンジの透かし、Codexは青枠と透明度72%の青い透かしで区別します。基本の文字色は白、`作業中` はミントグリーン、`確認待ち` はシアンです。文字はArial・太さ700で、タスクキーは上部ラベル9px、状態・セッション名16px、更新時間11.5pxです。概要キーは現在の文字サイズ（エージェント名約16px、件数20px）を維持し、フォントだけArialへ変更します。`作業中` は直径約26pxの太い回転インジケーターを1秒5フレームで動かし、`確認待ち` は赤丸を表示します。確認待ちへ変わった直後の10秒間だけ赤丸本体が明滅し、その後は点灯したまま静止します。

## Claude 5時間 + Codex 週間使用率

`Claude 5時間 + Codex 週間使用率` アクションは、1つのキーの上段へClaudeの5時間枠、下段へCodexの週間枠の使用率を表示します。Claudeは `25% / 5h`、Codexは `31% / w` の形式で期間を明示し、オレンジと青の太いバーで区別します。1分ごとに自動更新し、キーを押すと即時更新します。

サービスまたは契約プランが該当期間の使用率を返さない場合は、そのエージェントを `—` と表示します。認証トークンは既存のClaude Code/Codexログインから読み、保存しません。

## 表示する状態

| 表示 | 意味 |
| --- | --- |
| 待ちなし | 確認が必要な新しい返信はありません |
| 空き | そのキーへ表示する実行中セッションはありません |
| 作業中 | エージェントが考えているか、ツールを実行しています |
| 確認待ち | 返信が完了したか、質問への回答または実行許可が必要です |
| エラー | ツールまたは応答が失敗しました |

## インストール

1. `com.atsu.claude-code-status.streamDeckPlugin` をダブルクリックし、Stream Deckにインストールします。
2. Stream Deckアプリで、上記の表どおりに概要2キー、更新順タスク5キー、統合使用率1キーを配置します。
3. このソースフォルダで次を実行します。

```sh
npm run hooks:install
npm run codex-hooks:install
```

4. CodexとClaude Codeのタスク名は会話記録から補完されます。Claude Remote Controlで変更したチャット名も約15秒以内に自動反映します。プラグイン導入前から動いているClaude Codeセッションも、ユーザー名やホームフォルダ名ではなく実際のチャット名を表示します。短い「OK」「続けて」などは名前候補から除外します。
5. 実行許可待ちも即時表示する場合は、Codexで `/hooks` を開き、追加されたユーザーフックを確認して信頼します。

インストーラーは既存設定を置き換えず、目印付きの専用エントリだけをマージします。変更直前に他プロセスが設定を書き換えた場合は、上書きせずエラーで停止します。既存ファイルを変更する場合は同じフォルダへバックアップも作ります。

## アンインストール

```sh
npm run hooks:uninstall
npm run codex-hooks:uninstall
```

Stream Deck側は、Stream Deckアプリの設定から「Claude & Codex Status」をアンインストールしてください。

## 仕組みとプライバシー

Codexは `~/.codex` 内のローカルタスク記録から、実際のタスク名とターンの開始・完了を読み取ります。タスク名は `session_index.jsonl` にある同じタスクIDの最新名称を優先し、名称がなければタスク本体の記録へ戻ります。Claude Codeは、Remote Controlの変更可能なチャット名、`~/.claude/projects` 内の変更後セッション名、自動生成名、エージェント名、直近の内容が分かる依頼、最初の実際の依頼の順でタスク名を補完します。ローカルコマンド、画像通知、短い汎用的な返答は名前候補にしません。名称の補完や変更時刻は表示順に使わず、会話の最終更新日時順を維持します。Claude Codeと許可要求は公式ライフサイクルフックから、Stream Deckプラグイン内のローカルHTTPサーバー（`127.0.0.1:37654`）へイベントを送ります。

Remote Controlのチャット名を取得する場合だけ、macOSキーチェーンに保存されたClaude Codeの認証を使い、Claude公式の `api.anthropic.com` へセッション一覧を問い合わせます。取得するのはセッションIDとタイトルで、会話本文やツールの入出力は取得しません。Remote Controlを使っていないセッションや、ネットワークへ接続できない場合はローカル記録だけで動作します。

ファイル内容やツールの入出力は保存しません。セッションを見分けるため、タスク名を最大80文字に短縮し、Stream Deckには読みやすい太字で最大3行表示します。短縮した状態情報は、Stream Deckアプリの再起動後も表示を継続できるよう `~/Library/Application Support/Claude-Codex-Status/session-state.json` にローカル保存します。8時間以上更新のない状態は自動的に消去されます。

## 開発

必要環境はNode.js 24以降、Stream Deck 7.1以降です。

```sh
npm install
npm run validate
npm run pack
```

テスト状態を送る例:

```sh
npm run demo -- working claude
npm run demo -- attention codex
```

状態には `ready`、`working`、`attention`、`done`、`error`、`offline`、エージェントには `claude` または `codex` を指定できます。
